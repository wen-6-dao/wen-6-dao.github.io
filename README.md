# 个人在线简历（HTML 格式）

## 项目说明

单文件实现的在线个人简历（HTML + CSS + JavaScript，无外部依赖），适配 PC 与移动端，支持浅色/深色主题切换、滚动入场动画、卡片 3D 倾斜与光斑跟随等交互效果，并提供一键导出 PDF。

## 文件结构

- `index.html`：页面全部源码（结构、样式、逻辑、默认数据）
- `certs/`：证书图片（cert-1.jpg、cert-2.jpg）
- `README.md`：本说明文档
- `个人简历.zip`：本作业的提交压缩包

## 运行方法

直接双击 `index.html` 用浏览器打开即可，无需安装或联网。

## 内容编辑

页面右上角 ⚙️（或 Ctrl+M）进入内容管理（需管理员密码，首次打开时自行设置），数据保存在浏览器本地。
